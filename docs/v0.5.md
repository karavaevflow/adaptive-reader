## Delivered behavior

- **Knowledge Memory:** save a selected/current PDF/EPUB passage, write a source-linked reader note, or save a cited Companion/library answer. Cards distinguish author quotation, reader note and model inference; titles, comments and tags are editable. Original quotations are separate from reader/model text. Source returns retain Book UUID, source SHA-256 and SourceAnchor v1.
- **Canvas:** multiple named-by-default boards, explicit named relationships, clusters, drag, pan/zoom, viewport culling and source return. Accessible increment/decrement and movement commands use the same persistence path as dragging. Selection clears when changing boards or filtering; Return reveals the first matching card. Undo move and card-deletion Undo preserve neighboring edits and relationship endpoints.
- **Cross-book search:** bounded PDF/EPUB evidence, original-access/checksum checks, revision-keyed disposable caches, cancellation, per-book problems and visible truncation. Book/title/author/collection filters and Saved only are available. Author/collection metadata is editable in Timeline. Reader notes remain searchable if their original file is unavailable.
- **Local semantics:** saved-card ranking uses installed Apple sentence embeddings when available, with visible text-search fallback for unsupported/unavailable query languages. Derived vectors are bounded and invalidated on card mutations. No model assets are downloaded. This is retrieval, not a model-generated answer.
- **Comparisons:** select excerpts from two books, inspect the original text, verify either source and save a reader-authored connection, including on Canvas. Optional library AI reuses the configured provider and endpoint consent. Cited comparisons require evidence from at least two books; library answers cannot execute reader actions. Only explicitly selected bounded excerpts, titles and the question are sent on an explicit request.
- **Timeline:** actual EPUB chapters, available PDF outlines and explicitly saved ideas/events. Unavailable structure does not become invented chapters, characters or events.
- **Reading paths:** suggest a goal-based route from current matching/selected source excerpts, edit the goal/step titles, reorder/remove steps and mark completion. Routes persist and return to the exact sources. Suggestions are local retrieval order, not a claim of model planning or exhaustive coverage.
- **Open exports:** native Save exports readable Markdown with machine-readable anchor comments, and complete knowledge/graph/path JSON. Import merges unknown IDs while preserving existing edits. JSON does not include original book assets; unavailable book identities remain explicit rather than being silently rebound to a different source. More also resets the derived search index without changing books or user records.

View → Knowledge workspace (`⇧⌘J`), toolbar, More and Command Center share the application command. The reading surface remains the default. The owner has deferred connecting/evaluating a real AI model; no real-model answer quality, cloud latency or full-library reasoning is claimed. AI stays off by default.

## Storage and boundaries

Knowledge schema 1 lives under `Knowledge/Memory.json`. BookRecord 3, SourceAnchor 1, Notes 1 and Study 1 are unchanged. Typed KnowledgeCommand mutations run atomically through the existing LibraryStore actor. Each card has one to eight source references. Delete removes its placements/edges; Undo restores only those records, retaining unrelated changes. Archive import preserves existing IDs/edits. Schema-version and graph validation reject unsupported versions, duplicate IDs, missing endpoints and non-finite/out-of-range coordinates before writing.

The derived disk index is capped at 128 MiB, with bounded per-source passages and at most 500 books/400 search hits per query; visible messages disclose limits. Saved data is capped at 10,000 cards, 100 boards, 1,000 nodes/3,000 edges per board, 1,000 paths and 100 steps per path, within a 48 MiB archive. Canvas coordinates are bounded to ±1,000,000 points. Process-local semantic cache holds at most 2,000 vectors. Search/extraction stays off the UI actor. Source failures do not discard other books' results or saved notes. Image-only EPUB and locked PDF produce explicit unsearchable-source messages.

Native sandbox permissions remain those already approved for v0.4: user-selected Read/Write for Open/Save, read-only retained source-reference bookmarks, app sandbox and network client for explicitly configured AI. No original source is rewritten.
