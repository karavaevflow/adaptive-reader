# v0.5 — Connected knowledge

Implementation in progress on `codex/knowledge-v0.5`, stacked on the accepted v0.4 source. No v0.5 acceptance is claimed until the evidence below is complete.

## Scope

- Explicit user-owned Knowledge Memory: cards distinguish original quotations, reader notes and model inferences. Sources retain SourceAnchor v1, immutable source revision, quotation and human-readable location.
- Native Knowledge workspace reachable from View, toolbar, More and Command Center. Reader remains the default surface. Compact/wide layouts and RU/EN use Adaptive components.
- Reading Canvas: multiple boards, cards, named relationships, clusters, pan/zoom, drag and accessible movement commands; source return; persistence and open JSON/Markdown export.
- Cross-book local search uses bounded PDF/EPUB evidence, source checksums and explicit book/title/author/collection filters. Saved knowledge can use installed Apple sentence embeddings; unavailable languages fall back visibly to text search. No model download.
- Compare original excerpts locally, write a reader connection, or explicitly ask the configured Companion provider. AI defaults off. Library answers cannot execute reader actions; comparisons must cite at least two books. Real-model quality remains deferred by the owner.
- Timeline shows actual EPUB chapters, available PDF outline entries and explicitly saved ideas/events. It never fabricates events.
- Goal-based routes are suggested from available matching excerpts and remain editable/reorderable. No claim of exhaustive topic coverage.

## Stable storage and commands

Knowledge schema 1 is separate under `Knowledge/Memory.json`. Source assets, Books schema 3, Notes schema 1, Study schema 1 and SourceAnchor schema 1 are unchanged. LibraryStore atomically serializes typed KnowledgeCommand mutations. Per-node moves avoid whole-board overwrites. Card deletion removes its board placements/edges; Undo restores only those records and preserves neighboring edits. JSON import merges unknown IDs without overwriting existing edits; missing source references remain explicit and fail navigation clearly.

Disposable, revision-keyed search caches are under Cache/Knowledge. Access and source checksum are checked even when a cache exists. Extraction/search is cancellable on a worker; source errors are returned per book. Cloud mode sends only explicitly selected bounded evidence, titles and the question after destination consent validation. No request is sent on open/index/search.
