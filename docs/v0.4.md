# v0.4 — EPUB and learning (in progress)

This branch starts v0.4 on top of the v0.3 integration baseline. **It is not an accepted v0.4 release.** Cards, Recall, Markdown export, persistent highlights and Listen & Read are still pending. Real-model acceptance remains deferred by the owner.

## EPUB foundation

- DRM-free reflowable EPUB container, package manifest, spine, relative resources and linked non-spine footnotes. Fixed-layout and encrypted/obfuscated resources produce explicit unsupported states.
- ZIPFoundation 0.9.20 is pinned in both package resolutions; its MIT notice is bundled in the application. Archive entries stay in memory, with size/count limits, CRC checks and rejection of traversal, duplicates and symlinks.
- WebKit renders sanitized XHTML offline, preserving XML text order instead of reparsing tables as HTML. A restrictive CSP blocks authored scripts, remote resources, frames, forms and connections. Reader scripts run in an isolated content world. Only manifest assets are exposed by the custom resource handler; no extracted files or persistent browser storage.
- `ReaderEngine` now backs the shell through a format-independent reference. Native PDF adapters remain explicit. Navigation, search, palette and the new validated typography command share `ReaderCommands`.
- `EPUBTextLocator` version 1 contains a UTF-16 text offset and a validation quote, encoded deterministically inside `SourceAnchor` schema 1. It addresses the immutable sanitized source resource, independently of font size, typeface, line spacing or column width. Invalid resources, offsets and quotes fail explicitly.
- Appearance offers System/Serif, 12–36 pt, 320–960 pt columns and line spacing. Library copy/reference import, bookmarks, search, history, Focus and position restoration work through the shared session/storage paths. PDF-specific zoom, Spotlight and Mini Reader are disabled for EPUB.
- EPUB evidence uses the same `EvidencePassage`, BM25 ranker, request, provider and reviewed-action contracts as PDF. Building and retrieval run off the main actor and remain bounded/cancellable. No model is started or contacted when opening a book. The EPUB index is disposable in-memory state; the existing PDF disk cache keeps its own schema.
- BookRecord schema 3 adds explicit PDF/EPUB format and correct managed asset extensions. Versions 1/2 migrate atomically as PDF, preserving source bytes and existing data. ReadingState schema 1 gains optional EPUB typography; old records remain readable.

## Reproduction

```sh
python3 scripts/make-epub-fixtures.py
swift test
xcodebuild -project AdaptiveReader.xcodeproj -scheme AdaptiveReader -destination 'platform=macOS' build
xcodebuild -project AdaptiveReader.xcodeproj -scheme AdaptiveReader -destination 'platform=macOS' -only-testing:AdaptiveReaderUITests/OfflineReaderTests/testEPUBSearchReflowBookmarkAndRestore test
```

The project-authored MIT fixtures cover a long chapter, Russian/English text, illustration, footnotes, authored scripts, fixed layout, encryption and traversal. Their ZIP timestamps/order are deterministic. The corpus is a reproducible engineering fixture set, not a claim of broad compatibility across commercial publishers. Publication scripts, DRM, fixed layout, media overlays, audio/video and obfuscated fonts are not supported. Publisher CSS can vary; typography and palette acceptance on additional real books is still pending.

Protocol/design references: [EPUB 3.3](https://www.w3.org/TR/epub-33/), [ZIPFoundation](https://github.com/weichsel/ZIPFoundation).
