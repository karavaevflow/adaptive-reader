## Delivered behavior

- Reflowable DRM-free EPUB: offline manifest/spine/resources, chapter navigation, internal and non-spine footnotes with Back/Forward, search, copy/reference import, bookmarks and position restore.
- Appearance controls for System/Serif type, size, line spacing and column width. Versioned resource/UTF-16/quote locators remain tied to the original source across reflow and restart. Images retain their aspect ratio and colors.
- Study is a native side inspector at wide widths and a sheet in compact windows. Notes can be created/edited/deleted; cards have editable questions/answers, archive/unarchive, source return and portable JSON import/export. Imports require the exact same source revision, rebase the library-local book UUID and keep existing card IDs unchanged.
- Optional Recall uses the reader's own cards: reveal an answer, choose Again or Remembered, or stop. Review dates persist (Again: ten minutes; remembered intervals: 1, 3, 7… days, bounded at 365). No generated test responses or compulsory scores.
- Persistent colored highlights, a color filter, source navigation and deletion Undo. EPUB uses CSS custom highlights without changing source text nodes. PDF uses in-memory annotations backed by separate user records; original file bytes are never rewritten.
- Markdown export through the native Save dialog includes notes, cards, highlights and human-readable source labels. Machine-readable anchors are retained in comments. Card JSON can be moved to another managed copy of the same source.
- Listen & Read uses actual installed macOS AVFoundation speech, language/voice selection, 0.5–2× speed, optional text following, current-word highlighting, pause/resume/stop and persisted listening position. It continues from that position after restart. Source/window/app closure stops speech; voice preparation and between-utterance pauses preserve the user's intent. Speech services initialize only when requested.

View → Study (`⇧⌘L`) opens the tools. Select text, or use the current text block, then choose New note / New card / Highlight passage. `⌥⌘L` pauses or continues listening. Speed changes apply to the next spoken block.

## Contracts and storage

The shell retains `ReaderEngine`, typed `ReaderCommands` and `WorkspaceCommand`, with SourceAnchor schema 1 for PDF/EPUB/AI evidence. Text passages, highlight rendering and playback following cross this boundary. Speech following does not pollute navigation history. Native objects remain with their main-actor owner; speech callbacks cross actors using immutable identity/range values and ignore cancelled utterances.

BookRecord schema 3 adds PDF/EPUB format and correct managed extensions; schema 1/2 PDF records migrate atomically with source bytes and prior positions preserved. ReadingState schema 1 has optional EPUB typography. Study schema 1 stores cards/highlights/listening state separately from immutable assets and disposable caches; Notes schema 1 is unchanged. Atomic actor writes merge unrelated edits. Optional display quotations keep human paragraph breaks separately from canonical text ranges.

Canonical EPUB offsets do not depend on layout. Reading/evidence chunks respect actual paragraph boundaries, so minified XHTML does not join words from adjacent paragraphs. Source quote validation is bounded and rejects invalid offsets, surrogate splits, revisions and resources. Search is cancellable and bounded. The container rejects path traversal, symlinks, duplicate paths, invalid CRC/size, excessive resource counts and oversized content. Authored scripts/editability, remote resources, frames and forms are disabled; reader scripts run in an isolated content world.

User-selected-file Read/Write was explicitly approved on 2026-11-12 for native export. It grants only files selected in Open/Save, not arbitrary Documents access. Reference bookmarks still use read-only security scope, and source checksum tests remain in place. AI remains off; the owner's real-model check is deferred. EPUB evidence uses the shared provider/action contracts, but Recall/card authoring does not pretend to be a real model.

## Scope and practical limits

Supported EPUBs are reflowable UTF-8/UTF-16 XML publications with local resources. Fixed layout, DRM/encrypted/obfuscated resources, authored scripts, media overlays/audio/video and OCR are not implemented. The deterministic MIT corpus is engineering evidence, not exhaustive publisher compatibility. Complex publisher CSS can differ; Original remains available. PDF speech order follows available PDFKit text and may be imperfect in complex layouts. No cloud/model quality or inference benchmarks are claimed.

The performance harness uses a hidden native WebKit window and forced layout, not GPU/onscreen frame-presentation timing. Sampled additional WebKit RSS is an operational process estimate and excludes shared speech services/WindowServer. See the report for the investigation of historical CPU-timing drift and its interleaved old/new controls.
