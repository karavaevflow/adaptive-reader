# v1.0 — Public stable acceptance

The project is preparing **1.0.0-rc.1 (8)**. v1.0 stable is not declared. Candidate code preserves the v0.6 storage schemas and application identity. [Original specification](https://app.notion.com/p/4112088b02f681959e88f107a734b778) and [release gates](release-gates.md) define the outcome.

| Gate | Current evidence / remaining work |
|---|---|
| Upgrade | Frozen artificial v0.6 PDF/EPUB library, writer-source fingerprints, complete record preservation and previous/future schema tests. 73 core tests pass locally. |
| Installed binary | A dedicated CI test will unpack the production universal archive, use the real sandbox, import a PDF offline, load v0.6 notes/cards and PDF/EPUB panes, quit/reopen and verify source bytes. Pending first CI result. |
| Core/UI regression | Pending final candidate native/CI runs. Prior v0.6 source has passed acceptance. |
| Long session | Dedicated optimized 25-minute Mini Reader/auto-scroll CI job, with real elapsed samples and task shutdown. Pending first result. This runner is separate from the fixed control Mac. |
| Performance | Repeat fixed-corpus Release measurements on the M1 control Mac and investigate changes above 20%. Pending. |
| Visual/accessibility | Prior v0.6 RU/EN, Light/Dark, 800/1440 references remain the baseline. Candidate CI repeats regression and contrast checks. New installed-binary workflow references pending. Fresh system VoiceOver and Reduce Motion/Transparency runtime reviews remain open; silent AX checks do not substitute for them. |
| Platform | Minimum declared macOS 15.0. Current local Mac is 15.8.3; hosted macOS 15 runners use a later 15.x version. Exact 15.0 runtime acceptance is not claimed. |
| Distribution | Package script checks source/version/identity, universal architectures, sandbox/no-debugger entitlements, licenses, checksum and extracted signature. No Developer ID identity is installed. Local ad-hoc signing, no notarization. Public stable publication waits for open stable gates. |

Production-container tests refuse to run against an existing library or a normal contributor account. They seed artificial old records only after a fresh install and preserve the newly imported book/LastBook. This checks old data compatibility using genuine v0.6 writer output, not an old-binary installer or a downloaded/quarantined Gatekeeper flow. Ordinary test launchers mute speech; installed production tests invoke no speech/model action.

AI remains optional/off by default and real-model evaluation remains deferred by the owner. Reader translations, per-page OCR, helper-process memory and source-format limitations remain explicit in the v0.6 report. No new promise of arbitrary-edition alignment or OCR accuracy is made.
