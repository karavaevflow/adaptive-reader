## Candidate behavior and data

File → Back up library / Restore library backup use system file dialogs and the same typed command dispatch as menus, toolbar and Command Center. Archives contain managed sources and reader-owned positions, annotations, notes, Study, Knowledge and Extended Reading records. They exclude derived caches, provider/global appearance settings and externally linked originals. Restoring validates manifest paths, CRC/SHA-256, quotas and typed versions before an atomic directory swap into an empty library. The previous folder is retained for recovery. Cancellation is cooperative; pending transfers are drained on exit. Existing archives/current reader records are not silently replaced or merged. [Installation, update and backup instructions](distribution.md).

Production-container tests refuse an existing library or a normal contributor account. The installed app restores artificial v0.6 records through its normal picker; the runner never writes protected container files. This checks old-format compatibility using genuine v0.6 writer output in a new backup-format wrapper. It is **not an old-binary installer or browser-download/Gatekeeper test**. Contributor libraries/preferences are not used. Ordinary test launchers pass `-silentSpeechTest`; installed production tests invoke no speech/model action. Local speech research uses actual native synthesis at volume zero.

AI remains optional/off by default and real-model evaluation remains deferred by the owner. Reader-authored translations, explicit per-page OCR, helper-process memory and source-format limits remain as documented in [v0.6](v0.6.md). No promise of arbitrary-edition alignment or OCR accuracy is added.

## Verification boundaries

Backup/Restore uses the app's normal native permission path; TCC and entitlements are not weakened. UI checks invoke the alert's default action and require dismissal, wait for completed search and fully visible selected author quotations, and capture EPUB only after the actual visible paragraph exists. Failed/cancelled attempts and an early pre-paint capture are not counted as accepted evidence; final references come from the passed pinned-source run.

The five inherited opt-in skips remain explicit: two old Release-measurement entry points, manual VoiceOver, Reduce Motion/Transparency, and the comfort soak. The comfort scenario runs separately with real time in the candidate job; the four remaining opt-in methods are not newly passed CI cases. Fixed-Mac research above uses its own Release harnesses and does not assert those skipped XCTest methods ran.

The stable gates still require an exact-minimum-OS runtime, fresh system accessibility review and a real downloaded installation/old-binary replacement check on an appropriate clean Mac. Developer ID/notarization requires an owner's signing environment if that distribution route is chosen; none is installed here. Candidate status and a passing ad-hoc signature check do not substitute for Apple trust approval.
