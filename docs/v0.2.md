## Durable boundaries

SourceAnchor schema 1, ReadingState schema 1 and BookRecord schema 2 remain readable. New Comfort records have their own schema 1 and never modify source assets. Timers, automatic movement and active Mini windows are not resumed at launch. Reading summaries remain transient; no Reading Replay or Insights history is collected.

ReaderCommands owns the bounded Back/Forward history and validates Spotlight/text-block operations. PDFKit keeps selection, links and geometry. Native local input observation is scoped to the document's own view/window. A single scoped activity driver runs only while needed and cancels on closure. PDF reading blocks use available line geometry, rather than claiming EPUB paragraph semantics or OCR.

Mini Reader transfers one native PDFView between explicit AppKit hosts, preserving the same source and position. Floating level is an explicit, persistent per-book choice. Window close handling uses native willClose as well as SwiftUI disappearance.

## Reproduction

```sh
swift test
xcodebuild -project AdaptiveReader.xcodeproj -scheme AdaptiveReader -destination 'platform=macOS' test
sh scripts/benchmark-v02-soak.sh /private/tmp/adaptive-v02-soak.xcresult
```

Debug builds use a `.Development` bundle suffix. Release UI/performance runs use `ADAPTIVE_TEST_BUNDLE_SUFFIX=.UITesting`, keeping the production app and its sandbox separate. UITests/Info.plist records the actual target ID for process assertions and test-only diagnostics. Normal Release builds keep the production identifier and ignore fixture/diagnostic flags.

The opt-in soak uses real elapsed time, a Release application, the fixed 600-page PDF and Mini Reader/auto-scroll for 25 minutes. The application reports its own resident memory, ru_maxrss and CPU time through public self-process APIs; no sandbox privilege expansion or external process execution is required. Only fixture data and numeric metrics belong in committed evidence. Full desktop recordings remain temporary and are not published.

## Acceptance protocol

The v0.2 visual matrix captures Command Center, Reading tools, Spotlight and Mini Reader in RU/EN, Light/Dark, with 800 and 1440 pt main windows. Mini Reader has its own 420 × 600 pt content window. Screenshots use generated MIT fixture text, isolated storage and no personal library.

The timed soak is a single real 25-minute session, not five independent repetitions. Release engine comparisons and launch/panel measurements use five independent runs per scenario. Resident memory samples, process peak RSS and cumulative CPU seconds describe different metrics; startup peak includes PDFKit, chooser and accessibility caches. CPU display timings in the scroll harness are not GPU/compositor frame timings.

A first attempted soak was stopped by XCTest's default 600-second test limit, with the target still running. The reproduction script explicitly sets both default and maximum allowances to 1,800 seconds, and the opt-in case declares the same allowance. Interrupted attempts do not count as successful acceptance.
