# v0.3 — PDF AI Companion integration

Integration implementation and local checks are complete on `codex/ai-companion-v0.3`, stacked on accepted v0.2 `beddc1f`. Full CI passed on the frozen application source. Requirements: the approved release gates and [source specification](https://app.notion.com/p/4112088b02f681959e88f107a734b778), sections 8–10. The owner explicitly chose integration and tests now; connecting a real model is deferred. No real-model answer quality or provider latency is claimed.

## Implementation

- Optional native inspector, compact sheet, contextual selection actions and offline Command Center entry.
- Versioned, disposable local PDF evidence with stable IDs, source revision and SourceAnchor. Bounded BM25 lexical retrieval; no embeddings, vision or OCR claims. Cache schema 2 invalidates the earlier geometry cache; user-data schemas remain unchanged.
- Ollama NDJSON and OpenAI-compatible Chat Completions SSE transports. Model and exact endpoint are supplied by the user. AI defaults off; cloud consent is tied to the exact endpoint and model. Only the question, title, page and at most eight selected/retrieved excerpts enter an explicit request.
- API keys in Keychain, ephemeral URLSession, no cookies/cache or redirects. Local mode accepts loopback only; cloud mode requires HTTPS. No model calls on document open.
- Validated source citations and explicitly applied typed action proposals. No generated code, arbitrary file access or automatic mutations. Reader actions reuse existing commands and Smart Back.
- Explain Again retains the original evidence. New Topic cancels work and clears the answer context.
- Review/edit a note before saving it to separate schema-1 Notes records; Undo removes only that note. BookRecord 2, ReadingState 1 and SourceAnchor 1 are preserved.
- Smart Margins is opt-in and hidden in Focus. Wide layouts place hints in a separate rail; compact layouts use the inspector. Selection tools occupy a separate bar, preserving the actual PDF selection.

## Source and action boundaries

Cloud authorization is re-read at question start and immediately before provider use, including after Keychain access. Saving settings cancels and refreshes other windows sharing the library. Local requests bypass proxies and accept loopback only; all redirects are refused. Security IPC runs outside the main actor.

Indexing uses an immutable opened source snapshot in a separate worker. Evidence is capped at 32,000 passages / approximately 24 MiB of text; at most eight excerpts / 12,000 characters enter a model request. Selection context uses up to 1,400 characters from the first selected page; Copy uses the full native selection. PDF text ordering still follows available PDFKit line geometry and can be imperfect in complex layouts. Outlines supply chapter labels only when available. No OCR or image understanding is implied.

Answers must return the documented JSON shape, valid evidence IDs and one of book/general/insufficient labels. This validates source resolution and supported actions, not semantic truth. Proposed mutations require a user click; notes are editable before saving and have Undo. BookRecord 2, ReadingState 1, SourceAnchor 1 and existing v0.2 preferences remain readable.
