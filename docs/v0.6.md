## Scope

- Split Reading opens an independent PDF/EPUB engine, including another position in the same source. Scrolling, navigation and palettes are independent; same-source synchronization is explicit. Swap exchanges sources/positions. Application menus continue to address the primary pane; controls beside the second pane address that pane.
- Bilingual Reading pairs exact source fragments with reader translations, contextual explanations and saved vocabulary. A separate action prepares an explicit AI Companion question using the configured provider; no model is enabled, installed or called automatically. Arbitrary editions are not automatically aligned. Real-model quality remains deferred by the owner.
- Local Vision OCR uses explicitly supported CPU compute devices and processes one PDF page at a time, with bounded raster and text sizes, cancellation and revision-keyed derived cache. Recognized lines carry confidence and source geometry; uncertain text is marked beside the line. Search can use explicitly recognized pages without asserting native text-selection capability. Original files are unchanged.
- Replay stores local reading-action metadata, not screen recordings, question text or activity outside Adaptive. Insights separately estimates visible active reading time and counts explicitly completed sections and created notes. Both start disabled and have independent clear controls. Generation tokens reject queued writes after disabling or clearing.

## Stable contracts

ReaderEngine, ReaderCommands and SourceAnchor remain shared across formats. ReaderEngineFactory creates independent engines. BookRecord, ReadingState, Notes, Study and Knowledge schemas are unchanged. ExtendedReading schema 1 is stored under `ExtendedReading/Memory.json`, independently from source assets and derived `Cache/OCR`. The snapshot is capped at 16 MiB; OCR retains a bounded 16-page in-memory working set. Unsupported versions and malformed records are rejected atomically.

## Verified boundaries and reproduction

OCR is explicitly requested for the current PDF page. Up to 16 loaded recognized pages supplement search; the cache is reloaded on an explicit recognition request. This is not an automatic whole-book OCR index. Unsupported language assets are not downloaded. Confidence is a model score, not proof of accuracy; difficult layouts and even ordinary words may be wrong. Protected/copy-restricted documents retain explicit errors.

Bilingual translations/explanations are entered and reviewed by the reader. AI Companion only receives the chosen source after an explicit Ask using the existing configuration/consent boundary. Automatic edition alignment, an installed translation model and real-model quality are not claimed. Closing a split pane keeps its last separate position for explicit reopening; restoring the main library does not automatically open another book.

Replay/Insights store no outside-app activity or raw questions, start disabled and clear independently of saved translations. Time is assigned to the active pane's book and counted with monotonic samples only for an eligible visible window, up to 60 seconds after interaction. Completion is explicit, not inferred understanding.

Local native inspection used a separately signed QA copy with its own sandbox, imported only the fixed fixture, reproduced the primary-position shift and verified the active-pane controls. That QA process was quit. The primary anchor/clip observer lifecycle was fixed; passed source/geometry checks and final UI snapshots, not stale page counters, are the acceptance evidence.

Initial hosted arm64 runs stalled or lacked runner capacity. Serial native-framework contracts now log with a bounded timeout; CI uses standard macOS 15 Intel runners. An inherited Knowledge workflow exposed a real Metal-loader assertion (`Target device architecture is nil`) in the virtual GPU. Connections/clusters now use native AppKit/Core Graphics drawing, retaining the same projection, cards, controls and persistent graph. No OS graphics/security setting is disabled. PDF static text is verified by its actual AXValue/visible rectangle; WebKit exposes its web area separately from the native NSView identifier.
