# v0.1 — Offline PDF reader

The v0.1 implementation has completed local acceptance on 11 November 2026. Phase 0 remains complete. The feature is delivered through [PR #1](https://github.com/karavaevflow/adaptive-reader/pull/1); no v0.2 features are included.

## Delivered behavior

- Managed-copy and read-only linked imports, a local library, reading progress, title filtering and favorites.
- Native asynchronous PDF text search with snippets and SourceAnchor navigation. Scans without text expose an explicit unavailable state; OCR is deferred. Results stop at 1,000 with a refine-query prompt.
- Persistent page bookmarks, precise saved fragments, Focus and per-window Keep Awake. Closing a book returns to the library and releases the display-sleep assertion immediately.
- Security-scoped references survive normal Quit. Reauthorization requires the original checksum and preserves identity and annotations. Source files are never rewritten.
- Schema-1 metadata migrates to schema 2 without changing source bytes or reading state. Bookmarks remain separate from source files and disposable caches.
- Generic ReaderEngine search and typed commands preserve the PDF/EPUB/AI contracts. Only PDFReaderEngine retains native PDFSelection objects.

The full Release run skips two machine-dependent VoiceOver/reduced-effects tests; their separately completed Foundation reviews remain in [accessibility evidence](accessibility-review.md). No new runtime VoiceOver pass is claimed here. New controls use native accessibility labels and state values, exercised through AX queries in the offline flows.

Median PDFView opening on the fixed 600-page PDF is 48.08 ms Original / 65.88 ms selected; peak RSS is 51.6 / 92.3 MiB. With bounded search, median main-runloop delivery is 16.67 ms in both modes. These are CPU harness measurements, not GPU frame-time claims. Initial >20% CPU-display differences did not reproduce in interleaved builds. Two opening-time differences were isolated to first-page text capability work (4.63 / 9.34 ms); these measured costs are retained explicitly.

The full application protocol measures 5209.60 ms process launch to readiness, 1642.90 ms panel interaction, and 5851.67 ms large-PDF import to captured window. All include XCTest overhead. Launch/panel differences versus Foundation are −1.9% / +2.2%.

- Local archive: `/private/tmp/AdaptiveReader-v0.1.zip`, with an adjacent SHA-256 file.

The application is locally ad-hoc signed. Developer ID and notarization are not claimed; no owner certificate is required for development/testing. Books and searches remain local, with no model provider or network feature.

Locked PDFs must be unlocked before import. Image-only PDFs have no text search until a later OCR milestone. Complex, photographic and originally dark pages retain Original. Eligible selective-color pages rasterize at 2 px/pt and can soften at high zoom; Original remains available. A different source revision is a new import, not a silent replacement of existing anchors.
