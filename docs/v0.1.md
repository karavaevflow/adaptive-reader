# v0.1 — Offline PDF reader

Implementation and acceptance are in progress. Phase 0 remains complete; this document records the separate v0.1 gates. No v0.2 features are included.

## Implemented behavior

- Managed-copy and read-only linked imports, a local library, reading progress, title filtering and favorites.
- Native asynchronous PDF text search with snippets and source-anchor navigation. Scans without text expose an explicit unavailable state; OCR is deferred. Results stop at 1,000 with a refine-query prompt.
- Persistent page bookmarks, precise saved reading fragments, Focus and per-window Keep Awake. Closing a book returns to the library and releases the display-sleep assertion immediately.
- Security-scoped reference access survives normal Quit. Reauthorization requires the original source checksum and preserves identity and annotations. Sources are never rewritten.
- Schema-1 library metadata migrates to schema 2 without changing source bytes or reading state. Bookmarks remain separate from source files and disposable caches.
- Generic ReaderEngine search results and typed commands retain the common PDF/EPUB/AI architecture. Only PDFReaderEngine retains native PDFSelection objects.

On the fixed 600-page PDF, median PDFView opening is 48.08 ms Original / 65.88 ms selected; peak RSS is 51.6 / 92.3 MiB. With a bounded 1,000-result search, median main-runloop delivery remains 16.67 ms in both modes. These are harness measurements, not application-launch or GPU frame-time claims. Initial >20% opening differences against the older baseline were investigated with interleaved builds and did not reproduce; details and raw samples are retained.

## Limits and distribution

Locked PDFs must be unlocked before import. Image-only PDFs have no text search until a later OCR milestone. Complex, photographic and originally dark pages retain Original. Eligible selective-color pages rasterize at 2 px/pt and can soften at high zoom; Original remains available. Source revisions are immutable: a different PDF is a new import, not a silent replacement of existing anchors.

The application uses local ad-hoc signing. Developer ID and notarization are not claimed; no owner certificate is required for development/testing. Books and searches remain local, with no model provider or network feature.
